0/1 Knapsack using Dynamic Programming 🎒
Implementation of the classic 0/1 Knapsack Problem using Dynamic Programming in C++.

📖 Description
The 0/1 Knapsack Problem is a well-known optimization problem in computer science.

Given:

A set of items
Each item has a weight and value
A knapsack with limited capacity
The objective is to maximize the total value without exceeding the capacity.

Each item can either be:

Included (1)
Excluded (0)
Hence the name "0/1 Knapsack".

✨ Features
Dynamic Programming approach
Efficient solution compared to brute force
Calculates maximum achievable profit
Demonstrates optimal substructure and overlapping subproblems

🛠️ Technologies Used
C++
Dynamic Programming

📊 Complexity
Time Complexity: O(n × W)
Space Complexity: O(n × W)
Where:
n = number of items
W = knapsack capacity
